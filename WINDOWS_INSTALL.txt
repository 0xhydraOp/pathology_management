ACTIVATION-PENDING PRERELEASE 1.1.0-rc.1 — NOT FOR PRODUCTION LAB USE.
Windows binaries are unsigned. No production activation service is configured.
New registration, result editing and report finalization are unavailable.
Existing-record viewing, issued reprints, backup/export and recovery remain available.
Use synthetic data only. Read the included PRERELEASE.md before installation.

If you downloaded the **ZIP** named like:
    Patholy Management System-<version>-Windows-Install-Package.zip

  1. Extract the ZIP (right-click → Extract All…).
  2. Inside the folder you will find:
       •  Patholy Management System Setup <version>.exe   ← RUN THIS to install
       •  READ_ME_FIRST_Windows_Install.txt              (this guide)
  3. Double-click the **Setup .exe** — you should see the install wizard
     (license, choose folder, progress). That is a proper installation.
  4. After install, use the **Desktop** or **Start Menu** shortcut.

Do NOT look for a “portable” app .exe inside this ZIP — the package is only
the **installer** + instructions. There is no extract-and-run portable build.

If the program opens with NO wizard (no license, no “Installing…”):
  → You ran the wrong file, or an old portable zip from an older release.
  → Always run the file whose name contains **Setup** and ends in **.exe**.

DATA AND RECOVERY
Uninstallation preserves lab data. Preserve the data folder before reinstalling or recovery.
A fresh lab requires administrator setup; there is no default password.
See the included RECOVERY.md for encrypted backup/restore, lost-password recovery and limitations.
Close the lab application, then open the included Recover Administrator.cmd in the installation folder.
Alternatively run "Patholy Management System.exe" --recover-administrator.
Select the existing data folder, choose an existing administrator, enter a new password and confirm.
The installed app supplies its own runtime. Windows access to the data folder is required.
See RECOVERY.md; no hidden account is provided.
