PATHOLY MANAGEMENT SYSTEM — OFFLINE 1.1.0-rc.2
Unsigned Windows x64 prerelease; wider installation and lab validation remain pending.

1. Verify SHA256SUMS.txt, then run the matching Offline Setup installer.
2. Choose the installation folder. No internet, activation key or remote account is required.
3. On first launch create your own local administrator username/password.
4. Log in with those credentials. There are no default credentials.
5. Configure the local lab and validate its clinical rules before use.

Existing users/data keep their application and directory identity. Do not delete lab.db.
Offline conversion creates a verified recovery database before recognized activation cleanup.
Back up before upgrading. Portable encrypted backups require your chosen passphrase.
Uninstallation leaves lab data in place. Close the app before packaged administrator recovery.
See RECOVERY.md and OFFLINE_RELEASE.md beside the installed executable.
Windows 10/11 x64 supported; Windows 11 tested. Physical printing, elevated installation/upgrade
and actual power loss are NOT TESTED. v1.1.0-rc.1 activation requirements are historical only.
