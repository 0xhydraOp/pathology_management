# Controlled report amendments

An issued report is never edited in place. Version 1 remains the original snapshot; an authorized administrator supplies a correction reason, creates or resumes a separate draft, saves corrected results, and explicitly finalizes an appended version. Staff may view and reprint versions but cannot create or finalize corrections. All operations use the authenticated main-process actor, not renderer role or username assertions.

The Reports screen offers an issued-version selector. Amended prints identify the version, previous version and reason in both full-report and preprinted-pad modes. Long reasons use the existing table pagination; patient identity and version repeat on continuation pages. Current printer calibration remains physical alignment only. Selecting an older version does not overwrite the latest version.

Draft creation has a persistent request identity. Retries of the same request return the same draft; mismatched reuse fails. One active draft is allowed per order. Revision checks reject stale edits. Finalization commits snapshot, lineage, changed parameter IDs and authenticated audit together; duplicate finalization returns the committed version. A failed file replacement rolls back the in-memory database and leaves the original persisted report usable. Unsaved dialog values are lost on close; saved drafts survive restart. Cancellation retains its audit and does not erase issued versions.

Corrections cover results of existing ordered tests only. Patient/order identity, test membership and billed prices cannot be changed through this workflow. Unchanged rows retain archived results, intervals, units, flags and presentation. Numeric corrections use the saved interval and critical-rule provenance. Older snapshots without complete provenance withhold automatic flags and explicitly require manual clinical review. Derived values cannot be edited directly: dependency changes recompute only from captured expression, dependency units, precision and existing clinical guards; missing, cyclic, incompatible or non-finite saved formulas reject the amendment. Old derived reports without captured formula provenance require a separately validated correction workflow rather than guessing from today's catalogue.

Clinical review remains a human responsibility. The feature does not establish that medical values or formulas are clinically approved. Passwords, clinical audit history, billing and the original order result rows are not rewritten by amendments. Synthetic regression coverage exercises permission spoofing, idempotency, optimistic conflicts, invalid results, original preservation, audit persistence, failed save rollback, saved-formula recomputation and incomplete-provenance rejection.
